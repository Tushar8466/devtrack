## 🚀 Overview

**DevTrack** is an AI-powered platform that analyzes GitHub repositories to detect AI-generated code and verify developer authorship. This VS Code extension brings the power of DevTrack's Neural Intelligence Core directly into your editor — no tab switching required.

> *"Our mission is to help human ingenuity thrive in the age of synthetic code authorship."*

🌐 **Website:** [https://devtrack-seven.vercel.app](https://devtrack-seven.vercel.app)

---

## ✨ Features

| Command | Description |
|---|---|
| 🧬 **DevTrack: Analyze Workspace** | Runs a full neural authorship scan on your current workspace and shows real-time progress |
| 🔍 **DevTrack: Open Explorer** | Type any public GitHub repository and jump straight to the DevTrack analysis dashboard |

---

## 🧠 How It Works

```
1. Initialize Sync   →   Connects to DevTrack neural engine
2. Neural Scan       →   Deconstructs code authorship patterns in seconds
3. Extract DNA       →   Generates a comprehensive report on code provenance
```

After running **DevTrack: Analyze Workspace**, you'll see a step-by-step progress notification in the bottom-right corner of VS Code, ending with a final authorship integrity report.

---

## ⚡ Getting Started

1. Open the **Command Palette** (`Cmd+Shift+P` on Mac / `Ctrl+Shift+P` on Windows)
2. Type **`DevTrack`**
3. Choose either:
   - **`DevTrack: Analyze Workspace`** — to scan your current project
   - **`DevTrack: Open Explorer`** — to explore any GitHub repository

You'll also see the **`⚡ DevTrack: Active`** status indicator in the bottom-right status bar at all times.
